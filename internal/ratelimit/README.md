# Rate Limiting

Этот пакет реализует систему ограничения частоты запросов (rate limiting) для Telegram бота.

## Особенности

- **Токен-бакет алгоритм** с автоматическим восстановлением токенов
- **Разные лимиты** для разных типов действий (сообщения, файлы, кнопки, команды)
- **Автоматическая очистка** неактивных пользователей
- **Исключения для админов** - они не ограничены
- **Умные сообщения об ошибках** в зависимости от типа действия

## Типы действий

- `ActionMessage` - обычные текстовые сообщения
- `ActionFileUpload` - загрузка файлов и изображений
- `ActionCallback` - нажатия кнопок
- `ActionCommand` - команды бота

## Конфигурация

### Рекомендуемые лимиты (по умолчанию)

```go
Message:     100 запросов за 15 минут
FileUpload:  20 файлов за 20 минут  
Callback:    200 нажатий за 15 минут
Command:     20 команд за 10 минут
```

### Консервативные лимиты (больше защиты)

```go
Message:     50 запросов за 5 минут
FileUpload:  10 файлов за 10 минут
Callback:    100 нажатий за 5 минут
Command:     10 команд за 5 минут
```

### Либеральные лимиты (больше удобства)

```go
Message:     150 запросов за 20 минут
FileUpload:  30 файлов за 30 минут
Callback:    300 нажатий за 20 минут
Command:     30 команд за 15 минут
```

## Использование

### Инициализация

```go
// Создание менеджера с рекомендуемыми лимитами
manager := ratelimit.NewManager(ratelimit.GetDefaultLimits())

// Или с консервативными лимитами
manager := ratelimit.NewManager(ratelimit.GetConservativeLimits())

// Или с либеральными лимитами
manager := ratelimit.NewManager(ratelimit.GetLiberalLimits())
```

### Проверка лимитов

```go
// Проверка разрешения для конкретного типа действия
if manager.IsAllowed(userID, ratelimit.ActionMessage) {
    // Обрабатываем сообщение
} else {
    // Отправляем сообщение об ошибке
}
```

### Статистика

```go
// Получение статистики
stats := manager.GetStats()
fmt.Printf("Активные пользователи: %v\n", stats)
```

## Интеграция в Router

Rate limiting автоматически интегрирован в `Router.Handle()`:

1. **Проверка лимитов** происходит в начале обработки каждого обновления
2. **Админы не ограничены** - они могут использовать бота без ограничений
3. **Умные сообщения** - пользователи получают понятные сообщения об ошибках
4. **Автоматическая очистка** - неактивные пользователи удаляются из памяти

## Команды для админов

### `/ratelimit` - Статистика rate limiting

Показывает:
- Количество активных пользователей по типам действий
- Текущую конфигурацию лимитов
- Общую статистику системы

## Мониторинг

Система автоматически:
- Очищает неактивных пользователей каждые 5 минут
- Восстанавливает токены согласно конфигурации
- Логирует превышения лимитов

## Настройка лимитов

Для изменения лимитов отредактируйте конфигурацию в `config.go`:

```go
func GetCustomLimits() ActionLimits {
    return ActionLimits{
        Message: Config{
            MaxRequests:    120, // 120 сообщений
            WindowDuration: 15 * time.Minute, // за 15 минут
            RefillRate:     4,   // 4 токена в минуту
            RefillInterval:  15 * time.Second,
        },
        // ... другие типы действий
    }
}
```
